# MIDI Manager

[English](README.en.md) | [简体中文](README.md)

本地 MIDI 文件整理工具：扫描你电脑上的 MIDI 文件，自动建立曲库，帮你快速找到想要的曲子，并清理重复文件。

---

## 功能

### 扫描与整理

- 扫描一个或多个指定目录下的 MIDI 文件（`.mid` / `.midi`）。
- 自动解析每个文件的：文件名、路径、使用了哪些乐器、每种乐器的音符数量，并保存到本地曲库。
- **增量扫描**：再次扫描同一目录时，只处理新增或修改过的文件，不会重复解析。
- **实时进度**：扫描时实时显示当前正在处理的文件与计数；遇到超大目录可以随时点「停止扫描」，已处理的部分会保留。

### 重复文件处理

- 自动识别重复文件并分组：
  - **字节完全相同**（复制件）；
  - **乐器与音符数量结构相同**（可能是同一首曲子的不同版本）。
- 逐组查看确认，或使用 **「全部去重」一键处理**：每组默认保留最早入库的文件，其余按你的勾选删除。
- 删除前有二次确认——**删除是永久操作，无法恢复**，请谨慎操作。

### 组合查询

- 按「乐器 + 音符数量」组合筛选曲库。
- 两种匹配模式：
  - **精确匹配**：文件的乐器集合恰好等于你选择的乐器；
  - **包含匹配**：文件包含你选择的全部乐器即可，允许还包含其他乐器。
- 支持每乐器音符区间、总音符区间、文件名关键词、目录前缀过滤，结果分页展示，可直接用系统默认程序打开文件。

### 统计

- 文件状态统计（正常 / 重复候选 / 已删除 / 缺失 / 解析失败等）。
- 乐器分布 Top 10（仅常规乐器，不含打击乐细分）。

## 桌面应用使用说明

启动程序（`midi-manager.exe`）后，顶部有四个页面：

### 1. 扫描

1. 点击「浏览…」选择目录，或手动输入路径后回车，可添加多个目录；
2. 点击「开始扫描」，实时查看进度；大目录可随时点「停止扫描」；
3. 扫描完成后自动提示新增/更新/跳过/失败数量，并自动检测重复文件。

### 2. 文件库

1. 勾选要筛选的乐器（支持关键词过滤乐器列表）；
2. 选择匹配模式：精确 / 包含；
3. 可选：填写每乐器音符区间、总音符区间、文件名关键词、目录前缀；
4. 点击「查询」查看结果，分页浏览，点「打开」用系统默认程序打开文件。

### 3. 去重中心

- 查看所有待处理的重复候选组；
- 点击组可展开查看组内文件，勾选要删除的文件（最早入库的文件固定保留）；
- 组数很多时，直接用 **「全部去重」**：按默认规则（每组保留最早入库，其余删除）一键处理全部候选组；
- 删除前弹窗确认，确认后永久删除。

### 4. 设置统计

- 查看曲库路径、文件状态统计、乐器分布 Top 10。

## 命令行使用

程序还附带命令行工具（`midi-mgr.exe`），与桌面应用共用同一个曲库：

```text
# 扫描目录（可多个）
midi-mgr scan --dir D:\Music\midi --dir E:\midi

# 查询：精确匹配（乐器集合恰好等于所选）
midi-mgr query --instruments "Acoustic Grand Piano,Bass Drum 1" --note-min 0 --note-max 500

# 查询：包含匹配（包含所选全部乐器，允许更多）
midi-mgr query --instruments "Acoustic Grand Piano" --superset

# 支持按总音符区间、文件名关键词、目录前缀过滤，以及 JSON 输出
midi-mgr query --instruments Piano --total-min 100 --name "theme" --json

# 查看待处理的重复候选组（不删除）
midi-mgr dedup --dry-run

# 逐组交互确认删除
midi-mgr dedup

# 自动处理全部候选组：保留最早入库（oldest）/ 最新（newest）/ 路径最短（shortest）
midi-mgr dedup --keep oldest

# 查看曲库统计
midi-mgr db --info
midi-mgr db --stats
```

## 数据说明

- 曲库数据保存在：`%USERPROFILE%\.midi-manager\library.sqlite`（桌面应用与命令行共用同一份数据）。
- 删除重复文件为**永久操作**，被删除的文件不会进入回收站，操作前请确认。
- 扫描超大目录（几十万文件）时建议分批扫描，可随时停止，已处理部分会保留。
